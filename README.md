# HoangWholeFoods
CMPE 138 - Team 6 Project

Instruction to run program to ensure no errors are faced:

1. Create the DB and tables using the db_creation.sql file.
2. Run the homepage.py file
   - This will create the stores and the store_managers
3. Now run the db_testdata.sql file to insert some dummy data for products, categories. if you would like to test right away
4. If not then you can edit all the remaining tables using the frontend functions
